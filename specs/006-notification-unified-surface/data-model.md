# Data Model: Daily Notification Unified Surface

**Date**: 2026-09-17
**Spec**: [spec.md](spec.md)

## Entities

### UnifiedNotificationLayout (Redesigned)

The notification's visual structure after removing DecoratedCustomViewStyle.

**Collapsed layout:**
```
LinearLayout (root, NO background, NO system container)
  ├── LinearLayout (custom header: icon + "Luma Calendar" + timestamp)
  │     (previously hidden, now visible and styled)
  ├── LinearLayout (date row, horizontal)
  │     ├── LinearLayout (date column, weight=1)
  │     │     ├── TextView (primary date, SemiBold)
  │     │     └── TextView (secondary dates, Regular)
  │     └── LinearLayout (mini tile, subtle integrated bg)
  └── (no actions in collapsed)
```

**Expanded layout:**
```
LinearLayout (root, NO background, NO system container)
  ├── LinearLayout (custom header: icon + "Luma Calendar" + timestamp)
  ├── LinearLayout (date row, horizontal)
  │     ├── LinearLayout (date column, weight=1)
  │     │     ├── TextView (primary date, SemiBold)
  │     │     ├── TextView (secondary dates, Regular)
  │     │     └── TextView (daily message, Regular)
  │     └── LinearLayout (mini tile, subtle integrated bg)
  └── LinearLayout (actions row, horizontal)
        ├── LinearLayout (Today, compact glass)
        ├── LinearLayout (New Event, compact glass)
        └── LinearLayout (Remind Later, compact glass)
```

### Builder Configuration (After Fix)

| Property | Before (DecoratedCustomViewStyle) | After (No Style) |
|----------|-----------------------------------|-------------------|
| Style | DecoratedCustomViewStyle | None (default) |
| System header | Auto-generated by Android | Removed |
| Custom header | visibility="gone" | visibility="visible", styled |
| System container | Visible outer rectangle | Eliminated |
| System padding | Added by template | Eliminated |
| Custom content | Renders inside system container | Renders directly |

## Validation Rules

| Rule | Validation |
|------|------------|
| VR-001 | DecoratedCustomViewStyle MUST be removed from builder |
| VR-002 | Custom header MUST be visible and styled (replaces system header) |
| VR-003 | No system-generated container or padding around RemoteViews |
| VR-004 | Root layout MUST have no background drawable |
| VR-005 | Mini tile background MUST be subtle (#0DFFFFFF or less) |
| VR-006 | Primary date MUST not be truncated |
| VR-007 | All dates from device local time via DateUtils |
